# 道具工坊

依照 `Spec20260925.md` 開發的繁體中文靜態工具。僅使用 HTML、CSS 與原生 JavaScript，不需安裝套件、建置、伺服器或網路連線。

直接用現代版本 Chrome、Edge、Firefox 或 Safari 開啟 `index.html` 即可使用。也可以將此目錄放到一般靜態網站主機。專案未部署至外部服務。

## 使用方式

1. 到「Tag 管理」新增分類，填寫名稱及選填說明，ID 會自動產生。
2. 到「道具資料庫」建立素材或道具。ID 自動產生，名稱必填；說明、Tag 及組成均可留空。
3. Tag 下拉選單可搜尋並複選；組成清單會載入已建立的其他道具，可搜尋並複選。搜尋不會清除已選項目。
4. 使用卡片上的編輯、刪除管理資料。ID 為唯讀，Tag 與道具分別使用 `tag-0001`、`item-0001` 起始的流水號。新增時取該類現有流水號最大值加一，不補中間缺號，超過四位數會自然延長。匯入的流水號也計入；其他格式的既有 ID 保留且不參與計算。刪除最大編號後，該編號可能再次使用。編輯與匯入保留原 ID。被引用的素材須先解除引用才能刪除；刪除 Tag 會經確認後移除道具中的該 Tag。
5. 匯出 JSON 備份時，Tag 清單及每件道具的 `tags`、`components` 依 ID 升冪排序，數字部分按數值排列（例如 `item-9999` 在 `item-10000` 前）；不改變工作區中的原始順序。匯入時先驗證並顯示筆數，確認後取代目前全部資料，不會合併。可匯入 `sample-data.json` 體驗功能，其中配方僅為示範。

## 資料格式

### 複數新增 Tag 與黑暗模式

Tag 管理的上下兩處均提供「複數新增 Tag」。按「＋ 再新增一筆 Tag」可追加名稱、說明與自動流水號，寬螢幕有逐筆內容預覽。每筆會驗證必填與長度，並檢查批次內及與現有 Tag 的名稱重複；全部通過才一起儲存。

右上角可切換黑暗／淺色模式。首次依系統配色，手動選擇後會以獨立的 `mabim-workshop-theme` 偏好記錄保存在瀏覽器。儲存不可用時仍能在當前頁面切換，不影響道具資料。

### 複數新增道具

道具列表頂部與底部的「複數新增道具」可開啟批次表單。第一筆使用原本編輯介面，按下方「＋ 再新增一筆道具」追加欄位，每筆自動產生接續的 ID，可填名稱、說明並搜尋複選現有道具作為組成素材；追加的欄位組可移除。整批共用第一筆的 Tag，修改第一筆 Tag 會套用至全部待新增道具。批次中尚未儲存的道具不會出現在素材選單。

儲存時檢查每筆必填、長度、ID、引用與配方，以及批次內／與現有資料的名稱重複。全部通過才一次儲存；失敗時保留表單且不部分新增。關閉表單不會儲存未完成的批次。

追加的每筆道具也提供內容預覽：寬螢幕顯示於右欄，中等螢幕置於該筆下方，窄螢幕維持精簡表單。預覽即時同步該筆名稱、說明、共用 Tag 與組成素材；可直接移除該筆素材，共用 Tag 統一在第一筆調整。

新增／編輯視窗依寬度調整：小於 1000px 維持原本單欄；1000px 起將基本資料與分類／組成分成兩欄，內容預覽放在下方；1400px 起道具編輯使用三欄，右側顯示名稱、說明與已選內容，可直接移除 Tag 或素材。Tag 編輯在寬螢幕以基本資料與預覽兩欄呈現。寬螢幕的標題與儲存操作列在捲動時保持可見。

新增與編輯時，同類資料不可使用重複名稱（忽略前後空白，英文字母區分大小寫）；道具與 Tag 之間可以同名，編輯會排除該筆資料本身。匯入會檢查檔案內所有 Tag 與道具名稱，若有重複，以 alert 一次列出重複名稱及對應 ID，並停止匯入。匯入為取代模式，因此不與目前工作區的名稱比對。舊有本機資料仍可載入，方便逐筆修正重複名稱。

```json
{
  "version": 1,
  "tags": [{ "id": "material", "name": "素材", "description": "" }],
  "items": [
    { "id": "wood", "name": "木材", "description": "", "tags": ["material"], "components": [] },
    { "id": "handle", "name": "木柄", "description": "", "tags": [], "components": ["wood"] }
  ]
}
```

`tags` 與 `items` 必須是陣列；各類 ID 分別唯一。ID 為字串（匯入數字 ID 時轉為字串），最長 100 字元；名稱最長 200 字元；說明最長 10000 字元。道具的 `tags`、`components` 是 ID 陣列，可省略，省略視為空陣列。`description` 省略視為空字串。`version` 可省略，提供時必須為 `1`。匯出附帶 `exportedAt` UTC 時間。組成不含數量；重複引用會去重。

匯入上限 10 MB，拒絕重複 ID、不存在的引用、自我引用及循環配方。驗證失敗或取消不會變更現有資料。所有使用者文字以文字節點呈現，不作為 HTML 執行。

## 儲存與備份

資料儲存在目前瀏覽器的 `localStorage`（鍵名 `mabim-workshop-v1`），不會上传或跨裝置同步。清除瀏覽器資料會刪除記錄；私密瀏覽、本機檔案路徑及瀏覽器設定可能影響持久化，請定期匯出。開啟位置或網站來源改變時，請用 JSON 轉移資料。

若讀取本機資料失敗，程式保留原始內容而不覆寫；儲存失敗會顯示提示，當次資料仍能匯出。其他分頁更動資料時，本分頁會停止自動儲存，避免互相覆寫；請先備份，再重新整理。

## 驗證

有安裝 Node.js 時，可執行 `node --test tests/data.test.cjs` 檢查資料驗證、引用關係、循環、匯出再匯入及不合法格式。網站本身不需要 Node.js。
